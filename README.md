# Abhi Savaliya - Portfolio

A simple personal portfolio website made with HTML and CSS. It introduces Abhi, presents selected design work, and shares education, experience, skills and contact details.

## Run the website

Open `index.html` in a web browser. If you use Visual Studio Code, you can also open the project with Live Server.

## What is included

- A fixed navigation bar with links to each section
- About, selected work, experience, education, milestones, skills, certificates and contact sections
- Responsive layouts for desktop and mobile screens
- Local images and CV files in the `assets` folder
- Links to Abhi's email, LinkedIn and GitHub

## Files

- `index.html` contains the page content and section links.
- `style.css` contains the colours, layout, card styles and mobile adjustments.
- `assets/` contains the photos, portfolio images, certificates and CV.

## Design and CSS

The page uses a forest green and muted gold colour palette with light card backgrounds. The navigation links point to section IDs in the HTML. CSS Grid is used for the portfolio gallery and card layouts, while Flexbox is used for navigation and smaller groups of content. Hover styles give links and images a little feedback, and media queries stack the layouts on narrow screens.
